## SPECKit Plus – Short Note

SPECKit Plus is an SDD-RI (Specification-Driven Development with Reusable Intelligence) framework designed around one core principle:
“Capture intelligence, not just generate code.”

Instead of focusing only on producing working code, SPECKit Plus follows a Two-Output Philosophy:

Working Code (Ephemeral):
This is the actual feature or implementation created for the project. It delivers value but can be rewritten or replaced later as technologies evolve.

Reusable Intelligence (Permanent):
SPECKit Plus captures the thinking behind the code, such as reasoning patterns, architectural decisions, evaluation frameworks, and effective prompt templates.
These insights are stored (commonly in a history/ directory) and remain valuable for future projects.

By separating code from intelligence, SPECKit Plus enables developers to accumulate learning, improve decision-making, and reuse proven reasoning structures across new projects—even when the code itself does not transfer.


### /sp.constitution
Defines the permanent rules, purpose, and principles of the project so everything stays aligned. It acts as the project’s foundation and rarely changes.

### /sp.specify
Turns vague ideas into clear, complete specifications that answer “What are we building?”. Focuses on intent, constraints, success criteria, and non-goals.

### /sp.plan
Creates a detailed blueprint that answers “How will we build it?”. Breaks the specification into architecture, components, and ordered steps.

### /sp.tasks
Converts the plan into small, 15–30 minute actionable tasks with one clear output. Ensures work is organized, focused, and easy to verify.

### /sp.implement
Executes tasks in order using AI while showing progress at each checkpoint. The student stays in control and approves each step before continuing.
