# PART A
### What new improvements were made in gemini 3.0?
Gemini 3.0 comes with major improvements like stronger reasoning, much better multimodal understanding (text + images + video), a huge context window, improved coding abilities, and enhanced safety against wrong or harmful outputs. It understands complex tasks more accurately and works more reliably than previous versions.

### How does gemini 3.0 improve coding & automation workflows? 
Gemini 3.0 improves coding & automation workflows by enabling “agentic coding” — AI agents can plan, write, test, and validate code autonomously. With Google’s new Antigravity IDE, the agents get direct access to the editor, terminal, and browser, and they generate clear “artifacts” (plans, logs, screenshots) to show their work. Gemini 3 also supports “vibe-coding,” turning natural-language prompts into full apps. Its very large context window (for understanding big codebases), combined with deep reasoning, makes it strong in complex, multi-step development tasks.

### How does gemini 3.0 improve multimodal understanding?
Gemini 3.0 improves multimodal understanding by natively combining text, images, video, audio, and code in its inputs and reasoning. 

### Name any 2 developer tools introduced with gemini 3.0?
Here are two developer tools introduced with Gemini 3.0:

**Google Antigravity**: An agent-first IDE where AI agents get direct access to the editor, terminal, and browser to plan and execute coding tasks
**Gemini API (with Bash Tools)**: Includes a client-side bash tool for proposing shell commands and server-side tooling for multi-language code generation and secure prototyping.
